# Security policy

EventHarbor is under active development and is not yet intended for production
traffic or sensitive payloads.

Please report potential vulnerabilities privately to
`irfanburakozer@gmail.com`. Do not open a public issue containing credentials,
personal data, exploit details, or an active vulnerable endpoint.

The public demo will accept only synthetic data and preconfigured receiver-lab
destinations. Arbitrary outbound destinations will remain disabled until
endpoint verification, tenant quotas, and SSRF protections are complete.
