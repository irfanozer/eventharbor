# Contributing

EventHarbor is being built in public as an engineering case study. Focused bug
reports, design feedback, and small pull requests are welcome.

Before opening a pull request:

1. Explain the behavior being changed.
2. Add or update tests for the relevant guarantee.
3. Run formatting, linting, typing, and tests locally.
4. Do not commit credentials, real customer payloads, or private endpoints.
5. Update an architecture decision record when changing a system boundary or
   delivery guarantee.

Reliability and security changes should describe their failure modes, not only
the successful path.
